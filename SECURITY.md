# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or bypass technique within QuishGuard:

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainer or use GitHub's private vulnerability reporting feature.
3. Include detailed steps to reproduce the issue along with a safe, non-malicious proof-of-concept.

We appreciate responsible disclosure and will respond within 48 hours.
